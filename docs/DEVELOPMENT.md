# 开发说明

## 结构与版本

产品为「人生计算器 / Life Calculator」，对外 v2.0，package 版本 2.0.0。运行入口为根目录 `index.html`；`css/`、`js/`、`vendor/` 均为相对路径，支持在静态托管的子目录内使用。导航用明确的官网 HTTPS 外链；二维码始终指向 `https://maxhou.cn/static/life-calculator/index.html`，不附个人参数。

不需要构建、账号或后端。页面加载本地脚本、本地 CSS 与 Google Fonts 在线样式。字体详见 [依赖与致谢](../THIRD_PARTY_NOTICES.md)。PNG 是 Canvas 原生绘制；没有 PDF/JPG 功能。

## 计算与确认边界

- 选定阶段 `D = L − S`。`H = D × 8736`；活动需求为每期小时 × 每年期数 × 持续年数。每天/周/月/年的期数分别为 364/52/12/1；每期小时上限分别为 24/168/728/8736。
- 汇总先加未取整小时，再转换为显示值。PNG 活动与余额显示约等效年数；网页展开口径可看小时。
- 图谱的每行是 52 个等效周格，行数由终点决定，支持小数起止交集。网格连续着色只用于比较；多活动同格的点击与悬浮使用相同命中计算。
- 默认 `durationMode: 'stage'` 随有效 S/L 变化；明确 `manual` 保留年数，缩短预算后超过阶段仍保留并提示待修正。
- 旧无来源项不推断原意。依据已明确接受的兼容规则，草稿首次实际改变有效阶段时，全部旧无来源项随新跨度转为 stage，包括旧手填值。只打开、刷新、同值输入或临时无效后恢复原值不转换；此后改为 manual 的项继续保护。
- 只有生成才提交 confirmed；关闭/ESC 保留草稿。PNG 读取 confirmed，文案轮换只写独立轮换键；不能把未生成草稿画成新正式报告。

## localStorage 契约

保留 `lifeCalculator_` 命名空间与 `lifeCalculator_v3_draft`、`lifeCalculator_v3_confirmed`、`lifeCalculator_v3_rawBackup`。`lifeCalculator_png_quote_index` 独立轮换。产品 v2.0 与历史存储 schema v2/v3 是不同概念，不能按产品版本改键名。

首次原字符串备份不覆盖；活动稳定 ID 不因返回、生成、重排或模式变化复制。旧 V2 正式报告继续保留原 A 口径，直到用户生成新选定阶段报告。不可计算项须补齐或用户明确排除；写入或回读失败不能承诺刷新可恢复，且须保护原报告、备份及内存草稿。

数据在当前 origin，本地服务、官网、不同端口之间不自动迁移。PNG 无法恢复活动数据；这份浏览器内的首次备份也不是独立备灾文件。
